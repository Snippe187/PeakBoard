# PeakBoard

Modul von PeakVerse: Scoreboard (Objectives, Punktestaende, Anzeige-Plaetze, Teams) in der Weboberflaeche verwalten. Aenderungen werden als Entwurf gesammelt und mit einem Klick veroeffentlicht; was PeakBoard nicht selbst angelegt hat, ist geschuetzt. Vor jedem Veroeffentlichen wird der Stand gesichert (plugins/PeakBoard/backups).

Braucht PeakCore mit eingeschalteter Weboberflaeche (web.enabled). Baut zusammen mit den anderen Modulen zu PeakCore-<Version>.jar (Projekt PeakVerse/Bundle).
